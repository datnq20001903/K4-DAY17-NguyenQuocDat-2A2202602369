Keep CP3 changes and the fixed datasets intact. Agent replies and benchmark
execution remain later checkpoints.

1. Add failing unit tests for deterministic token estimates; persistent UTF-8
   profiles; corrections and noisy/question turns; bounded thread compaction.
2. Use `state/profiles/<sanitized-user>/User.md`. Preserve ordinary dataset IDs;

   resolved containment. Generated folder names must not impersonate normal IDs.
3. Support keyed facts and idempotent upserts without removing manual notes.
   Extract only affirmative personal facts and explicit response preferences.

   repeated compaction, fit whole fact lines within the summary budget, and keep
   recent messages verbatim. Facts omitted for space remain recoverable.
5. Implement the first two scaffold tests using the memory layer directly.
   Keep cross-session agent tests for the subsequent agent checkpoints.
6. Replay the fixed datasets in unit tests, run CP3 regressions, inspect the diff,
   review the implementation, and record CP4 conventions in `Analysis.md`.

Boundary: retained messages may themselves exceed the threshold. They stay
verbatim; a compaction is counted only when at least one old message is removed.
